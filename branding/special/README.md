# 📁 branding/special — FR/EN

## 🇫🇷 Version Française

Ce dossier regroupe les éléments **graphiques ou identitaires spéciaux** qui ne
rentrent ni dans `frameworks/`, ni dans `corporate/`, ni dans `labs/`.

Il sert à accueillir :

- assets uniques liés à un événement InterIA (annonce, milestone, commémoration)
- éléments visuels patrimoniaux (archives, logos historiques, symboles rares)
- prototypes graphiques "hors catégories"
- variations thématiques ou saisonnières
- matériel lié à des collaborations externes

➡️ En résumé : **un espace pour les assets exceptionnels**, non destinés à
l'utilisation quotidienne mais importants à conserver dans la charte globale.

---

## 🇬🇧 English Version

This folder contains **special-purpose visual or identity assets** that do not fit
into `frameworks/`, `corporate/`, or `labs/`.

It is used to store:

- unique assets for InterIA events (announcements, milestones, commemorations)
- visual heritage items (archives, historical logos, rare symbols)
- category-defying graphic prototypes
- thematic or seasonal variations
- assets related to external collaborations

➡️ In short: **a space for exceptional assets**, not meant for everyday use but
important for the global InterIA identity.
