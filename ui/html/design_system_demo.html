InterIA Design System v2.5

A reusable UI kit for InterIA repositories: style, layout, cards, gallery, math-lab overview, and multi-agent views.

🎛 Overview

💬
This page is a demo for the InterIA UI design system (v2.5). You can copy/paste the HTML fragments and reuse them in any InterIA-aligned repository, using the CSS files in ui/css/.

The layout, typography, cards, alert boxes, gallery and grids below are all driven by the shared CSS in interia.tokens.css, interia.base.css, and interia.components.css.

  • 01_delta3_first_experiments.ipynb
  • 02_lambda_estimation_primes.ipynb

Data layout
  • data/raw/ — raw exports (LMFDB, CSV primes, etc.)
  • data/processed/ — derived / cleaned datasets

✅ How to reuse this page

This demo page combines the InterIA layout, cards, gallery, lab layout, and multi-agent components. You can:

  • copy the CSS from ui/css/ into your project,
  • use this HTML as a starting point for your own GitHub Pages,
  • adapt sections depending on whether the repo is a framework, lab, or meta-project.

For detailed rules, refer to STYLE_GUIDE.md and the InterIA design system documentation in interia-style.
